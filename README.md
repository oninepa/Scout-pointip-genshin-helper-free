# Pointip — 원신 도우미 (Free)

원신 플레이어를 위한 데스크톱 도우미입니다.

## 다운로드

**최신 버전 (Windows 10/11 64-bit):**

👉 https://pointip.pages.dev



## 주요 기능

- **계정 현황** — 레진, 일일, 파견, 선계 등 실시간 확인
- **파티 추천** — 보유 캐릭터 기반 시뮬레이션 최적 조합
- **AI 도우미** — 게임 관련 질문에 즉시 답변
- **자동 업데이트** — 새 버전 자동 감지 및 설치

## 설치

1. 위 링크에서 `pointip-desktop_X.X.X_x64-setup.exe` 다운로드
2. 실행 후 설치 (SmartScreen 경고 시 "추가 정보" → "실행")
3. 앱 실행 → 로그인 → 사용

## 요구 사항

- Windows 10/11 (64-bit)

## 고지

본 프로그램은 **비영리 목적의 팬메이드 서드파티 도구**입니다.
호요버스(HoYoverse)와 공식적인 제휴, 협찬, 후원 관계가 없습니다.

원신(Genshin Impact) 및 관련 이미지, 캐릭터, 설정 등의 모든 지식재산권은
호요버스(HoYoverse)에 귀속됩니다.

본 프로그램은 호요버스의 팬 콘텐츠 가이드라인을 준수합니다.
호요버스는 언제든지 본 프로그램의 배포 중단을 요청할 수 있으며,
요청 시 즉시 배포를 중단합니다.

본 프로그램은 "있는 그대로" 제공되며,
사용으로 인한 어떠한 손해에 대해서도 책임지지 않습니다.
